# 七政

三维轨道与侧栏历象对照，把**农历、节气、星象**放在同一屏里读；教学向观天授时示意，不是算命 App。

**版本** v1.0.2 · **技术栈** Vue 3 · Vite · Three.js · Vue Router · **许可** MIT

## 「七政」释义

出典：《尚书·舜典》「璇玑玉衡，以齐七政」。通常指**日、月**与**金、木、水、火、土**五星。本站以此为名，做轨道与历法对照。算法与星象均为**近似 / 示意**，非官方历书、非观测星表、非精密星历。

## 历象主页

### 三维场景

- 日—地—月与五星的压缩轨道示意；黄道、节气圈、月相与行星方位随所选日期联动
- **星象层**：西象（IAU 88 示意）· 古象（陈卓体系量级示意，含三垣·二十八宿·北斗及展开星官）· **全部**（两层同显）
- **题名 / 隐名**：控制星官与星座名称标签显隐
- 星空装饰：星场、星云、小行星带、彗星等
- **岁差**：「岁差」滑杆（公元前 2000 → 公元 2100）。北天极沿极路径环①缓慢漂移，「极星」由右枢更替为勾陈一；历法冬至点相对恒星背景约 50″/年西移。教学示意，约 2.6 万年一周；默认年份 2000（J2000 现行）
  - ① 极路径环：北天极绕北黄极画出的圆周（半径≈黄赤交角 23.44°），环上标注勾陈一 / 右枢 / 织女一三个极星时代参照

### 轨道 / 地面

- **轨道**：俯视压缩太阳系，便于对照历法与黄道
- **地面**：从地表仰望天球；按观测经纬度与当地恒星时倾转；底部方位罗盘显示方位角与仰角（近天顶时显示「天顶」）
- 观测位置：预设城市（北京 · 上海 · 广州 · 成都 · 西安 · 拉萨 · 郑州 · 苏州）、自定义经纬度、浏览器定位
- **时间加速**（地面）：播放 / 暂停；速度 1 小时/秒（默认）· 1 天/秒 · 7 天/秒 · 30 天/秒（历法示意区间约 1900–2100）

### 历象侧栏

- 公历、农历（含闰月）、道历、岁星（太岁）
- **干支四柱**（年·月·日·时；教学纪时，非运势）
- 当前节气、距下一节气天数、月相与月龄、今日小知识
- 当日传统节日与近期节日列表，可跳转日期

### 日期与交互

- 顶栏公历日期；桌面 `←` / `→` 换日（Shift 为 ±30 日）；触屏顶栏 ‹ ›
- 三维内横拖拨日（桌面 Shift + 左键；触屏长按后横拖），松手可有惯性
- **默认**：恢复日期、相机、星象层、视角、观测地与侧栏等初始态
- 古象下点击有文化文案的星官名，可开「星官故事」卡片（由来 · 典故 · 今用）

### 移动端

- ≤720px：侧栏默认可收起，全屏三维；顶栏换行
- `viewport-fit=cover` 与 safe-area；可添加到 iOS 主屏幕
- 触屏：单指旋转 · 双指缩放平移 · 长按拨日；首次粗指针设备可有操作提示

## 列宿

- 左侧星空、右侧歌诀或西座列表；点选 / 滚动与高亮联动
- 星象层同样为西象 | 古象 | 全部；支持题名 / 隐名
- 歌诀中的星官名可打开星官故事

## 羲和

- 自先秦星经至清钦天监相关人物纵览
- 按时代分期与人物列表浏览；展开可见生平、主要成就与相关历法

## 操作摘要

| 平台 | 三维 | 换日 | 星象 / 历象 |
| --- | --- | --- | --- |
| **桌面** | 左键旋转 · 右键/中键平移 · 滚轮缩放 · Shift + 左键横拖拨日 | 顶栏选日期 · `←`/`→`（Shift ±30 日） | 星象层 · 题名/隐名 · 轨道/地面 · 右侧历象可收起 |
| **触屏** | 单指旋转 · 双指缩放平移 · 长按后横拖拨日 | 顶栏 ‹ › · 日期选择器 | 同上；侧栏「历象」展开/收起 |

地面视角下左键 / 单指环视天空；顶栏可播放时间加速并切换速度。

### 历法与轨道

- **节气**：太阳视黄经定气（教学近似）
- **朔望 / 农历**：参考 Meeus 等公开公式的示意实现（含无中气置闰）
- **道历年数**：公历年 + 2697（以公元前 2697 甲子为元年的常见口径）
- **干支四柱**：年柱依农历岁首口径示意；月柱依节气建月；日时按北京时辰；教学展示
- **三维轨道**：半径为教学压缩；行星方位为日心黄经近似，与历法 JD 联动
- **地面观星**：天球按当地恒星时与纬度倾转；方位 / 高度为标准时角公式的教学近似
